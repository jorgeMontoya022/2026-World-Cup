# 2026-World-Cup
Sistema de gestión del Mundial 2026. Incluye diseño de base de datos relacional y aplicación de escritorio (sin frameworks) conectada a un SGBD. Administra equipos, jugadores, técnicos, grupos, estadios y sedes. Incorpora login con roles (admin, tradicional y esporádico), bitácora de accesos, consultas avanzadas y generación de reportes en PDF.
